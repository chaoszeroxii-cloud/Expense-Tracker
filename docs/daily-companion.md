# ติดตามรายวันและวางแผนชีวิต

## ยอดคงเหลือสะสมบนหน้าหลัก

เปิดได้ที่ **ตั้งค่า → หน้าตาแอป → แสดงยอดคงเหลือสะสมบนหน้าหลัก** ค่าเริ่มต้นปิด
ทั้งบัญชีใหม่และบัญชีเดิม การตั้งค่านี้ผูกกับบัญชีและใช้ต่อได้เมื่อเปลี่ยนอุปกรณ์
ยอดแสดงในบัตรสรุปหน้าหลักทั้งโหมดจดอย่างเดียวและโหมดวางแผน โดยรวมรายรับหัก
รายจ่ายที่บันทึกทุกเดือน แสดงยอดศูนย์และติดลบได้ และปรับตามการแก้หรือลบรายการ
ยอดนี้มาจากรายการใน MoneyFlow จึงอาจต่างจากเงินในบัญชีธนาคาร และแยกจากวงเงินใช้ต่อวัน
การเริ่มบัญชีใหม่ทั้งหมดจะปิดตัวเลือกนี้อีกครั้ง

ก่อนนำเวอร์ชันนี้ขึ้นใช้งาน ให้รัน migration `1785410000000-HomeCumulativeBalance`
บน backend ตามขั้นตอนปกติ ไม่ต้องเพิ่ม env

## จดให้ง่ายขึ้น

- **หน้าหลัก → รายการปักหมุด → จัดการ:** เก็บรายการที่ใช้บ่อยได้ 20 รายการ ทั้งรายรับ
  และรายจ่าย กดปักหมุดเพื่อเปิดร่างของวันนี้ ปรับยอดหรือรายละเอียดได้ก่อนบันทึก
- **จดย้อนหลังและนำเข้า:** เพิ่มหลายรายการ เลือกวันที่และหมวด แล้วกดตรวจรายการก่อน
  ยืนยันบันทึก ครั้งละไม่เกิน 100 รายการ เลิกเลือกแถวที่ยังไม่พร้อมได้ แถวเหล่านั้นยังเก็บ
  เป็นร่างต่อหลังบันทึกแถวที่เลือกแล้ว
- **CSV:** รองรับไฟล์ไม่เกิน 1 MB รวมข้อความมีเครื่องหมายจุลภาค/ขึ้นบรรทัดใหม่
  เลือกคอลัมน์และรูปแบบวันที่ให้ตรงกับไฟล์ รองรับ ค.ศ. และ พ.ศ. หมวดที่จับคู่ไม่ได้
  ต้องเลือกเอง ประเภทที่ระบุแล้วไม่รู้จักจะหยุดนำเข้า ถ้าไม่เลือกคอลัมน์ประเภท
  ร่างจะเริ่มเป็นรายจ่ายและแก้เป็นรายรับได้ ไม่มีการบันทึกทันทีที่เลือกไฟล์
- **ใบเสร็จ:** รองรับ JPEG/PNG/WebP ไม่เกิน 5 MB กดอ่านรูปเพื่อส่งให้บริการ AI
  ที่เซิร์ฟเวอร์ตั้งค่าไว้ ผลลัพธ์เป็นยอด วันที่ และชื่อร้านในร่าง ต้องตรวจและเลือกหมวด
  ก่อนบันทึก ความแม่นยำขึ้นกับภาพและบริการ ไม่ถือเป็นหลักฐานว่ายอดถูกต้องแล้ว
- รายการที่ดูซ้ำจะต้องยืนยันแยก การลองบันทึกชุดเดิมซ้ำด้วยรหัสร่างเดิมไม่เพิ่มยอดซ้ำ
  ทั้งชุดบันทึกในธุรกรรมเดียว หากแถวใดไม่ผ่านจะไม่บันทึกแถวอื่นบางส่วน
- ร่างเก็บแยกบัญชีในแท็บปัจจุบันและอยู่ต่อเมื่อรีเฟรช ไม่ได้ซิงก์ข้ามอุปกรณ์

## ทบทวนและค้นหา

มีรายการหนึ่งรายการไม่ได้หมายความว่าจดครบทั้งวัน หน้า Home มีส่วน **ทบทวนรายวัน**
พร้อมวันที่ล่าสุด 14 วันและตัวเลือกย้อนหลังได้ 90 วัน เปิดประวัติของวันนั้น จดรายการ
ตกหล่น แล้วค่อยยืนยันหรือเปิดทบทวนใหม่ได้ การแก้รายการจะเปิดวันนั้นให้ทบทวนใหม่

รายงานรายสัปดาห์แยกรายจ่ายทั่วไปจากรายการที่ผูกกับบิล และจะไม่สรุปว่าใช้เงินลดลง
ถ้ายังไม่ได้ทบทวนครบทั้งสองสัปดาห์ ปุ่มทบทวนวันที่ตกหล่นเปิดหน้าทบทวนได้โดยตรง
นี่คือการยืนยันของผู้ใช้ ไม่ใช่การตรวจยอดกับธนาคาร

ประวัติค้นหาจากฐานข้อมูลทั้งหมดตามขอบเขตที่เลือก ไม่ติดเพดาน 500 รายการเดิม
เลือกข้ามเดือน ช่วงวันที่ หมวด และรายรับ/รายจ่ายได้ แสดงครั้งละ 50 รายการ ยอดรายวัน
ข้างรายการรวมเฉพาะรายการในหน้านั้น ส่วนยอดเดือนด้านบนเป็นยอดเต็มก่อนกรอง

## บิลและแผนเงิน

- **บิลที่ต้องดูต่อ:** รวมบิลค้างและใกล้กำหนด เลื่อนเตือนเป็นพรุ่งนี้ได้ เปิดบิลแล้วเลือก
  จ่ายและบันทึก หรือเชื่อมรายจ่ายที่จดไว้ในเดือนปัจจุบัน เพื่อไม่บันทึกซ้ำ
- จ่ายบิลของเดือนถัดไปล่วงหน้าได้เมื่อยืนยันเอง รายจ่ายลงวันที่จ่ายจริง การเปิดแจ้งเตือน
  หรือมองเห็นบิลในอนาคตไม่ได้สร้างรายจ่าย
- แจ้งเตือนบิลนอกแอปเปิดแยกได้ เลือกล่วงหน้า 0–14 วัน และใช้เวลาที่ตั้งไว้ใน Settings
  ต้องตั้งค่า Web Push และอนุญาตบนอุปกรณ์ก่อน ระบบส่งสรุปบิลไม่เกินหนึ่งครั้งต่อวัน
  บิลที่จ่ายแล้วหรือเลื่อนเตือนไว้ไม่รวมในการส่ง ส่วนรายการในแอปใช้ได้โดยไม่ต้องเปิด Push
- **วางแผนตามวันเงินเดือน:** ระบุวันเงินเดือนและวงเงินต่อรอบซึ่งรวมบิลแล้ว เมื่อเปิดใช้
  Home คำนวณจากรอบนี้และกันยอดบิลค้าง/บิลถึงกำหนดในรอบ วันที่ 29–31 ใช้วันสุดท้าย
  เมื่อเดือนนั้นสั้นกว่า ไม่สร้างรายรับอัตโนมัติ แผนรายเดือนเดิมพับไว้ดูประกอบ
- **จำลองแผนเก็บเงิน:** เลือกเป้าหมาย ยอดเก็บปกติ และยอดเพิ่มต่อเดือน ดูเดือนที่จะถึง
  เป้าหมายและตัวอย่างวงเงินที่เหลือ เริ่มนับเงินเก็บสิ้นเดือนนี้ ไม่รวมผลตอบแทนลงทุน
  ปุ่มยืนยันเปลี่ยนเฉพาะวันเป้าหมาย ไม่เปลี่ยนยอดเก็บจริงหรือวงเงินให้อัตโนมัติ

## การเปิดใช้ในสภาพแวดล้อมอื่น

ต้องรัน migration `1785300000000-DailyCompanion` ก่อนใช้ backend รุ่นนี้
ใช้ `npm run build` แล้ว `npm run migration:run` ใน backend หรือให้ `start:prod`
ทำตามขั้นตอน migration เดิม ตารางใหม่ไม่เปลี่ยนยอดธุรกรรมเก่า ไม่ใช้ synchronize

อ่านใบเสร็จใช้ `OPENROUTER_API_KEY` และการตั้งค่า vision/เพดานค่าใช้ AI เดิมของระบบ
Push ใช้ VAPID, subscription และตัวเรียกงานแจ้งเตือนเดิม เมื่อไม่ได้ตั้งค่า บันทึกเอง
นำเข้า CSV และติดตามบิลในแอปยังใช้ได้ รายละเอียดทดสอบอยู่ใน
